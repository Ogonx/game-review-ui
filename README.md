# Game Review UI

Frontend for my personal game review platform, built with React and deployed on Vercel.

## Live Site
https://game-review-ui.vercel.app

## Backend API
https://gamereviewapi-production.up.railway.app/swagger

## Tech Stack
- React
- Axios
- React Router
- Deployed on Vercel

## Features
- Search and browse games powered by RAWG API
- View reviews and aggregated scores
- Admin-gated review submission and deletion
- Admin-gated game management
